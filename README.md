# Akela Server — Paper 1.16.5

Конфигурация сервера Minecraft на базе **Paper 1.16.5**.

## 🔌 Плагины
| Плагин | Назначение |
|---|---|
| AuthMe | Авторизация (для пиратских аккаунтов) |
| EssentialsX | Основные команды (`/rtp`, `/spawn`, `/home` и др.) |
| EssentialsSpawn | Управление спавном |
| LuckPerms | Система прав и рангов |
| SkinsRestorer | Скины для пиратских аккаунтов |
| WorldEdit | Редактор мира |
| WorldGuard | Защита территорий |
| AkelaAntiCheat | Античит |
| Vault | Экономика |
| ProtocolLib | Зависимость для плагинов |

## ⚙️ Особенности конфигурации
- **Режим:** Пиратский (`online-mode=false`) с защитой через AuthMe
- **Язык:** Русский (AuthMe, Essentials, SkinsRestorer)
- **Anti-XRay:** Включён (режим 2 — самый надёжный)
- **Пароли:** BCRYPT хэш
- **Случайная телепортация:** `/rtp` — до 25 000 блоков

## 🚀 Запуск
```bat
start.bat
```

> ⚠️ Миры, базы данных игроков и .jar файлы не хранятся в репозитории.
